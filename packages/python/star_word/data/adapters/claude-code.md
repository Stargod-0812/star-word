1. 起草中文文字时即按上述规则约束用词与结构。
2. 机械规则（词组）违反即为硬错。

## 输出前自检（forcing function）

生成任何中文段落后，在输出前回答以下 6 个问题。任何一条答 yes → 重写再输出。

1. **铺垫检测**（气-01）：第一句删掉，第二句能独立成文吗？能 → 首句是废话，砍掉。
2. **废话检测**（气-02）：这段里有没有一句是「正确但无用」的？有 → 砍掉那句。
3. **立场检测**（气-03）：这段有没有做出判断或取舍？还是在罗列「各有优劣」？罗列 → 给结论。
4. **深度检测**（气-04）：回答的是用户字面问题，还是背后真正的问题？表层 → reframe 再答。
5. **密度检测**（气-05）：三句能说完的话，用了几句？超过 → 压缩。
6. **节奏检测**（式-08）：段落里的句子长度是否趋同？是 → 刻意加短句断句或长句展开，打破单调。

## 例外原则

规则为清晰表达服务，不是目的本身。若严格执行会让句子变蠢、变别扭、变不像人话，破例。
但要知道自己在破例 —— 不是默认忽略。
