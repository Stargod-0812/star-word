# 卡门的门 · 系列存档

作者：**卡门的门**（早期笔名 **卡门**）

## 系列顺序

1. **折服** — 吴曼与小胡，高中宿舍事件
2. **驯服** — 张平、刘璐与张亮平
3. **收服** — 小耀、林莉与黄哥/道馆线
4. **迷魂** — 小詹、小骆、陈蕾丹、谢桐与三尸
5. **归魂**（续集）— 四部主角汇聚，接《迷魂》结局之后

## 时间线说明（重要）

**四部曲的现实故事基本在同一现代时间线交叉发生**，彼此勾连（李猛、张亮平、黄哥、大修、三尸、小组等）。

《迷魂》序章「二十二年前」仅为**回忆/闪回**（吴曼、陈蕾丹、吴叔与三彭镇/农场），**不是**主线相隔二十年。

续集《归魂》从《迷魂》农场夜战、医院醒来之后接续，并回接《折服》《驯服》《收服》各线人物状态。
